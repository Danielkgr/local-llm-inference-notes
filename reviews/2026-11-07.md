# Repository and host review, 7 November 2026

The repository had fallen behind both machines.  Its front page described one
24 GB card, its method required unnecessary reference reruns, and its harness
example read as current configuration.  The hosts now use different runtimes,
two-card resource routing on Box, and a complete compact testing procedure.

There were also errors in the portable tools and claims that went beyond the
evidence.  This review updates the documentation and fixes the identified code
issues.  It makes no change to either host's serving configuration.

## Coverage

Repository review covered all sixteen existing notes, the front page, method,
licence and security policy, harness example, standalone tools, task
generators, task definitions, tests, dependency requirements, and CI.  The
existing untracked September handover was preserved.

Host review covered allowed inference configuration, service and package
metadata, runtime guards and selected engine settings, routing source, shared
acceptance and retrieval code, backup and updater documentation, and
maintenance records relevant to the current setup.  Top-level maintenance
inventories were used to locate changes missing from the repository.  Selected
final records were checked against later adoption or recovery records, rather
than assuming the first result was the final outcome.

The [evidence file](../evidence/2026-11-07-review.json) records hashes for 31
Box sources and 26 Strix sources.  It also contains selected adoption
measurements, the 6 November Strix gate outcomes, and observed configuration.
These are existing records, not measurements taken during this review.  The
source files remain on the named host and are not published here.

Documents trees, associated session content, chat databases, credentials, and
general session stores were excluded.  No inference endpoint was called, no
model was loaded, and no maintenance window, update scan, or host health script
was run.  The global hold remained in place.  Unrelated application internals
and private operational records were outside the review.

## Remaining limits

The specialist Box lane has an incomplete performance record.  Paired model
variants often reuse primary measurements and receive light routed checks.
Those rows must not be read as independent full-suite measurements.

The portable evaluation suite has limited task coverage and known ceiling
effects.  Best-of retries change the success criterion.  Different task sets
are not comparable experiments merely because their percentages can be printed
together.  The synthetic legal tier has no published model results here.

The context tool supports direct llama-server flags, not arbitrary shell logic,
macros, proxies, or every backend's configuration.  SQLite must parse the
stored chat JSON to extract metadata.  The privacy boundary is that message
bodies do not leave SQLite for Python.  The GPU helper is best effort, has
bounded waits, and does not provide mutual exclusion or fail-closed admission.

The download helper checks size and range, not cryptographic identity.  A
server can change a file without changing its size.  Source hashes remain
necessary for model provenance.  The GGUF tool identifies header metadata, not
model quality or tensor integrity.
